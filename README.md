## 📌 Overview
**Elevatr** is an AI-powered career guidance platform designed to provide personalized career insights, mentorship, resume feedback, and real-time opportunity tracking for students and early professionals.

The platform addresses the lack of centralized, personalized career guidance by offering an adaptive ecosystem tailored to individual skill sets and career goals.

## 🎯 Key Features
- 🔍 **Skill Gap Analysis** – Identifies missing skills based on user profile and goals  
- 🤖 **AI-Powered Career Guidance** – Personalized career recommendations  
- 🧑‍🏫 **Mentorship Support** – Guided learning and mentorship resources  
- 📄 **Resume Feedback** – AI-assisted resume evaluation and suggestions  
- 🇮🇳 **India-Specific Opportunity Tracking** – Curated internships and job opportunities  
- 🔐 **Secure Authentication** – Firebase Auth 2.0 for secure user management
